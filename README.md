
# GitHub Practice Project

A simple HTML-only personal profile website created by Samuel to practice Git and GitHub commands.

## Project Overview

This project is a basic personal profile website built using only HTML. It helps beginners understand Git version control and learn how to upload projects to GitHub.

## Features

- Personal introduction
- About Me section
- Skills list
- Learning goals
- Contact information
- Simple HTML structure

## Technologies Used

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Edit the HTML file and add your personal information.

## Git Commands Practiced

### 1. Initialize Git

```bash
git init
git status
```

### 2. Stage and Commit Files

```bash
git add .
git commit -m "Initial commit"
```

### 3. Check Changes

```bash
git diff
git status
```

### 4. View Commit History

```bash
git log
git log --oneline
```

### 5. Create and Switch Branches

```bash
git branch feature
git switch feature
```

### 6. Merge Branches

```bash
git switch main
git merge feature
```

### 7. Connect and Push to GitHub

Repository: [Samuel's GitHub Repository](https://github.com/samuelperumalla/23091a32d0)

```bash
git remote add origin https://github.com/samuelperumalla/23091a32d0.git
git branch -M main
git push -u origin main
```

If `origin` is already configured, check it with `git remote -v` instead of adding it again.
